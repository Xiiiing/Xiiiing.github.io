## 关于我

你好，我是 Xiiiing，计算机硕士，关注计算机视觉与医学影像。目前的学习主要围绕数字病理、全切片图像（WSI）与多实例学习（MIL）展开，也喜欢 Web 开发、知识整理和简洁的界面设计。

这座个人主页汇集我的近况、研究兴趣和项目入口。希望每次回看，都能看到一些积累，也看到想法逐渐成为作品的过程。
